# 产品分析模板库

## 市场规模估算模板

TAM/SAM/SOM 计算：
- TAM = 全球/全国潜在用户数 × 客单价
- SAM = 可触达市场 × 客单价  
- SOM = 3年内可获取市场份额 × 客单价

## 竞品分析框架

### 竞品选择标准
- 直接竞品：相同目标用户 + 相同核心功能
- 间接竞品：相同目标用户 + 不同解决方案
- 潜在竞品：可能进入该领域的玩家

### 竞品分析维度
- 基本信息、产品定位、功能架构、用户体验、运营策略、用户反馈、优劣势总结

## 用户画像模板

包含：基本信息、行为特征、需求与痛点、目标与动机、影响因素、引用语录

## SWOT 分析模板

- Strengths (优势)
- Weaknesses (劣势)
- Opportunities (机会)
- Threats (威胁)
- 战略矩阵：SO/WO/ST/WT 策略

## 用户需求优先级矩阵

高重要性 + 低满足度 = P0 (立即做)
高重要性 + 高满足度 = P1 (保持优势)
低重要性 + 低满足度 = P2 (暂缓)

## 数据来源清单

- 市场数据：艾瑞、易观、Statista、Gartner
- 竞品数据：App Store、七麦数据、SimilarWeb
- 用户数据：问卷调查、用户访谈、社交媒体
- 趋势数据：Google Trends、百度指数、微信指数
