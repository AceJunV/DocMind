# 深度创角 — 功能描述

## 概述
在新增角色弹窗 `UnifiedAddModal` 中新增第4个 tab「🎯 深度创角」，提供自由对话式角色创建，AI 通过逐轮深入追问，在充分理解用户需求后生成角色。

## 入口
- `AgentListPage.tsx` — UnifiedAddModal 新增 tab，4个 tab 并列：
  ```
  📋 预设模板 │ ✏️ 自定义 │ 🤖 AI 生成 │ 🎯 深度创角
  ```

## 交互流程

### Phase 1 — 自由描述
用户自由输入想法，AI 回应并对内容深入追问，逐步收拢角色定义。

- AI 先回应用户内容（表示理解），再自然追问 1-2 个相关问题
- 不设固定步骤，对话由用户内容驱动
- 轮数不限制，6轮起可为确认条件

### Phase 2 — 确认反问触发
满足以下任一条件时，AI 整理当前已收集的角色参数，反问用户：

**条件 A：** 用户对同一维度（风格、性格、专业背景等）反复补充或修改
**条件 B：** AI 检测到用户在绕圈子，没有提供新信息

**反问格式：**
> 根据我们刚才的对话，我整理了一份你的角色需求：
> - 角色类型：教研老师
> - 关注维度：课程设计
> - 性格特点：严谨、直接
> - ......
>
> 请问这是你想要的方向吗？

### Phase 3 — 确认生成
- 用户回应"是/对/差不多"等确认 → AI 收到确认信号
- **触发 LLM 调用**：以当前对话上下文生成最终 JSON
- `parseAgentJSON` 解析并展示预览卡片（同 AI 生成的结果形式）
- 用户可保存或继续修改
- 用户回应"不是/还要改" → 回到 Phase 1 继续对话

### 确认输出方式
用户确认后，前端再调一次 LLM（使用 `chatCompletion`）生成最终 JSON，不预先生成。

## 关键交互规则

| 规则 | 说明 |
|------|------|
| 对话驱动 | AI 不按固定脚本走，每轮先回应再追问 |
| 确认时机 | 6轮后可触发，但无硬性上限 |
| 重复检测 | 同一维度反复修改 + 绕圈子无新信息 |
| 参数展示 | 确认反问时展示文本参数列表，非结构化预览 |
| 最终生成 | 用户确认后调 LLM 输出 JSON → 解析 → 预览卡片 |
| 保存 | 复用现有 `preview` + `handleSave` 逻辑 |
