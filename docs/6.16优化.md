# 6.16 优化记录

## 一、深度创角功能（新建）

**文件：** `frontend/src/pages/agents/AgentListPage.tsx`

### 新增内容

#### 1. Deep Create Prompt (`DEEP_CREATION_PROMPT`)
- **第4个 tab** — `UnifiedAddModal` 新增 `'deep'` tab，入口为「🎯 深度创角」
- **自由对话式角色创建** — AI 不按固定步骤，通过逐轮深度追问理解用户需求
- **单次 LLM 调用** — 用户确认后，AI 在同一消息直接输出 JSON（修复了此前 Phase 2 + Phase 3 两次调用导致模型报错 "Cannot read 'image.png'" 的问题）
- **回复格式约束**：
  - 禁止使用 Markdown 符号（`**` `-` `#` `>` 等）
  - 每轮分两段：1-2 句理解 + 1 个追问
  - 每次只问一个问题，控制在 4 句话以内
  - 汇总信息时用纯文本表格（空格对齐），不用列表符号
- **多轮深挖示例** — 3 轮追问示例引导 AI 基于新信息继续深入同一方向
- **对话流程** — 4 步流程：自由描述 → 深挖 2-3 轮 → 确认补充 → 输出 JSON
- **JSON 字段名** — name, avatar, tagline, color, category, focusDimension(选填), personality(directness/strictness/humor/empathy 1-5), expertise[], behavior(style/catchphrase), system_prompt

#### 2. DeepCreateModal 组件
- 聊天界面 + 右侧预览面板
- 状态管理：messages, input, loading, preview
- `processLLMResponse` — 解析 JSON 生成预览卡片
- `handleSend` — 调用 `chatCompletion` 发送 DEEP_CREATION_PROMPT + 对话历史
- `handleSave` — 保存角色到本地 store，复用 Agent 数据结构

#### 3. parseAgentJSON 函数
- 从 LLM 响应中提取 JSON 对象
- 校验 `name` 和 `personality` 字段
- 返回解析后的角色数据

#### 4. 工具函数/类型补充
- `AIMsg` 接口（`role: 'ai' | 'user'`, `content: string`）
- `Loader2` 图标导入（loading 动画）
- `AddAgentTab` 联合类型新增 `'deep'`
