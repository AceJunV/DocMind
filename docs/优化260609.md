## 三、评审报告导出图片优化

### 3.1 问题

旧方案使用 Canvas 手动绘制简化版报告图片，格式与页面展示不一致。

### 3.2 方案

替换为 `html-to-image` 库的 `toPng` 方法，直接截取页面渲染内容：

- 安装 `html-to-image` 依赖
- 使用 `toPng(el, { pixelRatio: 2, skipFonts: true })` 生成高清截图
- 截图前隐藏交互元素（按钮、链接、固定定位面板）
- 截图后恢复所有元素可见性
- 下载方式：data URL → Blob → `URL.createObjectURL` → click download（避免控制台警告）
- 删除旧的 Canvas 手动绘制代码（约 120 行）

**新增依赖**: `html-to-image@1.11.13`

**涉及文件**: `pages/reviews/ReviewDetailPage.tsx`

## 五、研讨室新增 — 文档选择抽屉

### 5.1 需求

在研讨室页面直接新增研讨室时，弹窗中新增「选择研讨文档」功能。

### 5.2 实现

| 功能点 | 说明 |
|--------|------|
| 触发条件 | 仅在无 `review` prop 时显示（从 ChatListPage 创建） |
| 文档选择区 | 虚线按钮，选中后显示文档名 + 可更换 |
| 抽屉位置 | 紧贴弹窗右侧外部（`absolute left-full top-0`） |
| 抽屉内容 | 搜索框 + 已完成评审的文档列表（文档名 + 精确时间） |
| 搜索 | 按文档标题过滤 |
| 选中效果 | 自动填充主题「关于《文档名》的评审讨论」，用户可修改 |
| 议程生成 | 进入研讨室后由 `buildAgendaFromContext` + `TopicPool` 统一生成 |

### 5.3 弹窗布局优化

- 弹窗使用 `flex flex-col` + `max-h-[90vh]`
- 底部按钮 `shrink-0` 常驻
- 角色列表改为 2 列网格（`grid grid-cols-2`）
- 抽屉动画：从弹窗右边缘推出（`animate-slide-in-right`）

**涉及文件**: `components/ui/ChatRoomConfigModal.tsx`、`index.css`

## 七、议程生成逻辑统一

| 场景 | 议程来源 |
|------|---------|
| 有书签标记（agendaText） | 书签内容作为议程 |
| 无书签，从评审报告创建 | `buildAgendaFromContext` → TopicPool（high 建议 + 争议焦点） |
| 无书签，从研讨室选择文档创建 | 同上，进入房间后由 useEffect 统一触发 |

所有议程项初始状态为 `pending`，需要用户手动点击才会发起讨论。
