# 优化 260608 — 评审书签三态 + 研讨议程联动 + 手动推进议题

## 概览

本次优化围绕评审报告的书签系统、研讨室议程联动、以及研讨室交互流程三大模块进行，覆盖从评审报告页到研讨室的完整用户流程。

---

## 一、评审报告书签系统

### 1.1 三态星标

| 状态 | 图标 | 交互 |
|------|------|------|
| 未标记 | 灰色空心星星 | 点击弹出分类选择弹窗 |
| 已标记 | 黄色实心星星 | 点击取消标记 |
| 已讨论 | 绿色 CheckCircle | 只读，不可点击 |

- 已讨论态在进入研讨后由系统自动标记
- `BookmarkableParagraph` 组件统一管理三态渲染

### 1.2 弹窗定位修复

- 弹窗从 `absolute` 改为 `fixed` + `getBoundingClientRect()` 定位
- 使用 `createPortal` 挂载到 `document.body`，解决 `transform` 祖先元素裁切问题

### 1.3 提分思路回滚

- 从整段 article 级标记回滚为每个 paragraph 独立标记
- section 标记格式：`提分：${section.title}`

### 1.4 右侧浮动面板 (FloatingBookmarkPanel)

- 拆分为活跃标记 + 已讨论折叠区（默认收起）
- 活跃标记点击跳转到文档对应位置（`scrollIntoView` + 高亮闪烁）
- 已讨论项显示删除线 + 灰色
- 统计文案区分：`已标记 N 处 · 已讨论 N 处`

### 1.5 书签数据流

- `ReviewBookmark` 类型新增 `discussed?: boolean` 字段
- `reviewBookmarkStore` 新增 `markAsDiscussed(reviewId)` action
- 进入研讨室时，有 agendaText 则调用 `markAsDiscussed` 标记所有当前书签
- `agendaText` 仅含未讨论标记，已讨论标记不进入议程

## 二、研讨议程联动

### 2.1 ChatRoom 类型扩展

- `ChatRoom` 新增 `bookmarkAgenda?: string` 字段
- 创建研讨室时将 `agendaText` 存入 `bookmarkAgenda`

### 2.2 议程生成逻辑

| 场景 | 研讨室侧边栏议程 |
|------|------------------|
| 无书签标记 | 自动从 review/document 生成议程（不变） |
| 有书签标记 | **仅显示标记内容，完全替代自动议程** |

- `buildAgendaFromContext` 增加 `bookmarkAgenda` 参数
- 有值时按 `\n` 拆分为独立条目，跳过 TopicPool
- 每条 bookmark 独立一行（不再用 `；` 合并同类）

### 2.3 研讨室侧边栏精简

- 移除"文档预览"面板
- 移除"评审焦点"面板
- 只保留"研讨议程" + "参与者"
- 参与者栏常驻左下方（`shrink-0`），议程区域可滚动（`flex-1 overflow-y-auto`）

### 2.4 聊天消息不再插入议程

- 删除 `ChatRoomConfigModal` 中 `addMessage` 插入议程消息的代码
- 议程内容仅通过侧边栏和 `pendingTopics` 展示

## 三、研讨室交互流程重构

### 3.1 不自动发起讨论

- 移除 `useEffect` 中的自动 kickoff 逻辑
- 保留系统欢迎消息（不再触发 AI 回复）

### 3.2 手动点击议程发起

- 议程项所有状态可点击（pending/active/done）
- 点击后：
  - 设为 `active` → 发送用户消息「我们就「xxx」这个议程进行研讨」
  - 触发 `runDiscussionRound` 开始 AI 讨论

### 3.3 议题切换

- 点击不同议题时：
  - 自动发送「xxx议题我们先放一放，我们先研讨xxx议题」
  - 当前活跃议题回退为 `pending`
  - 新议题设为 `active`
- 点击同一议题不触发

### 3.4 议题状态

| 状态值 | 显示名 | 判定方式 |
|--------|--------|---------|
| `pending` | 待研讨 | 默认初始状态 |
| `active` | 研讨中 | 用户点击议程项 |
| `done` | 已研讨 | 用户点击"通过本提议"按钮 |

- 所有议程初始状态改为 `pending`（不再默认 `active`）
- 移除 `runDiscussionRound` 末尾的 `completeAgendaTopic` 自动推进

### 3.5 "通过本提议"按钮

- 位于聊天输入框上方（ChatToolbar 之前）
- 仅当有 `active` 议题时显示
- 点击后调用 `markTopicDone` 将当前议题标记为 `done`

### 3.6 参与者交互

- 点击侧边栏参与者 → 在输入框插入 `@角色名 `
- 保留原有输入 `@` 触发下拉选择功能

## 四、导航与页面跳转

### 4.1 返回逻辑

- `ChatRoomConfigModal` 创建房间后 `navigate` 带 `state: { from: '/reviews/{reviewId}' }`
- `ChatRoomPage` 返回按钮读取 `location.state.from`，从评审报告进入则返回评审报告，否则返回研讨室列表

### 4.2 ChatListPage 房间卡片

- 加 `HelpCircle` 图标，hover 显示议程内容
- tooltip 改用 React state 控制显隐（解决 CSS group-hover 闪断问题）
- 内容自动循环滚动动画
- 议程条目加序号标签（1. 2. 3.）
